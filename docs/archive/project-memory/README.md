# Project-memory archive

This directory preserves complete historical project-memory snapshots. They are
provenance artifacts, not cold-start instructions or current status.

Use `AGENTS.md`, `docs/current/STATUS.md`, `HANDOFF.md`, and `TODO.md` for current
work. Read a snapshot only to answer a specific historical question.

The archived instruction file is intentionally named `AGENTS.full.md`, not
`AGENTS.md`, so it cannot create a nested agent-instruction scope.
