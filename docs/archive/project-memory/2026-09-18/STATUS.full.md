## What R6d accepted

### Recovery budget and capacity

One exact `RecoveryBudget` checks both complete paths against a shared retained
horizon:

```text
hard_total    = normal_ACK_age + hard_liveness + attach + replay_to_app_ACK
reverse_total = normal_ACK_age + reverse_stall + authenticated_hint
              + attach + replay_to_app_ACK
hard_total <= retained_horizon
reverse_total <= retained_horizon
```

At `100,000,000 bit/s` and `500ms`, each direction requires checked storage of
`6,250,000B`, represented by exactly 100 five-millisecond records of `62,500B`.
Overflow and either path at `500ms + 1ns` fail before actor/root construction.

### Production-shared root

`QuinnClientRoot::start_initial` owns:

- full Quinn composition and the sole TCP factory;
- prepared transactional OPEN and exact retry/abort ownership;
- checked command, flow, effect, replay, message/byte, and timer bounds;
- category-fair nonpolling progress under one bounded work budget;
- one monotonic production epoch for checked `SimTime` mapping;
- semantic terminal and transport liveness separation;
- shutdown and transport-fatal structural/semantic drains; and
- a final zero witness that includes reducer/session residual ownership.

### Lifecycle cutoff repair

Final review found a real shutdown presignal/TOCTOU window. The accepted repair
linearizes every bounded synchronous live turn against the shutdown CAS using
the lifecycle watch lock. `ShutdownRequested` never enters live service. If an
async command was already selected, shutdown returns that exact input as
`RootNotRunning(ShuttingDown)` without reducer, factory, FIFO, reply, or wire
commit.
